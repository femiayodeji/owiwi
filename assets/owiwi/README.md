# Owiwi mascot assets

| File | Use |
|---|---|
| `idle.png`, `happy.png`, `thinking.png`, `celebrate.png`, `sad.png`, `sleepy.png` (+ `@2x`, `@3x`) | Mascot states, rendered by `<Owiwi />` through `OWIWI_ART` in `src/components/owiwiAssets.ts` |

All of these are cut from `docs/design/owiwi-brand-sheet.png.png` by `scripts/extract-brand-art.py`. Nothing is redrawn. When the designer delivers the originals, replace these files and keep the names. Do not redraw the owl or substitute emojis.
