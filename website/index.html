Install on Android

Five quick steps, about a minute.

  1. Download

    Tap Download for Android. If Chrome warns you, tap Download anyway.

  2. Allow the install

    When asked, tap Settings and turn on Allow from this source.

    Not asked? Settings › Apps › Special app access › Install unknown apps.

  3. Install

    Open owiwi.apk from Downloads and tap Install.

  4. Play Protect warning?

    Tap More details › Install anyway.

  5. Open Owiwi

    Pick topics, set times, add your AI. You're in.

Needs Android 7.0+ on a 64-bit phone.

Updating? Install the new APK over the old one. Your data stays.

Stay safe: download only from this site or GitHub.

Set up your AI

Pick a provider, get a key, paste it in Owiwi.

New here? Pick Gemini. It's free and needs only a Google account.

Google Gemini Recommended

Free tier, no card needed.

  1. Open aistudio.google.com/apikey
  2. Tap Create API key and copy it.
Modelgemini-3.5-flash-lite

In Owiwi: Gemini › paste key › Test connection › Save.

Groq

Free tier, no card needed. Very fast.

  1. Open console.groq.com/keys
  2. Tap Create API Key and copy it. It's shown once.
Modelllama-3.3-70b-versatile

In Owiwi: Groq › paste key › Test connection › Save.

OpenRouter

Free for models ending in :free.

  1. Open openrouter.ai/keys
  2. Tap Create Key and copy it. It's shown once.

Custom

Any OpenAI-compatible API, like DeepSeek or Together.

  1. Create a key in their dashboard.
  2. Copy the base URL, e.g. https://api.deepseek.com/v1
  3. Find the model ID in their docs.

In Owiwi: Custom › base URL, model, key › Test connection › Save.

Where? Setup step 4, or later in Settings › LLM providers.

Your key is safe. It stays on your phone and goes only to your provider. This site never sees it.

Test connection failed?

401 / 403 Key rejected
Paste the full key again. Paid providers need credit.
429 Too many requests
Free limit reached. Wait a minute and retry.
Network error
Check your connection, or the Custom base URL.
Anything else
Usually a wrong model ID. Pick one from the app's list.

Questions

Is Owiwi free?

Yes. Only your AI provider may charge, and Gemini, Groq and OpenRouter's free models don't.

Is there an iPhone version?

Not yet. Android only for now.

Why not the Play Store?

Not yet. For now you install the file directly, so Android asks permission and may show a warning.

What leaves my phone?

Headline searches to Google News, and one request per digest to your AI. Nothing else.

Does it work offline?

Yes, once today's digest has loaded.

What if I miss a day?

Owiwi forgives one missed day a week. Miss two in a row and your streak restarts.
